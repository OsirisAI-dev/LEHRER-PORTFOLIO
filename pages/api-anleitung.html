Warum einen API-Schlüssel statt Ihrer Zugangsdaten verwenden?

Pourquoi utiliser une clé API au lieu de vos identifiants ?

Aus wichtigen Sicherheitsgründen fragt diese Wörterbuch-App niemals nach E-Mail-Adressen oder Passwörtern. Ein API-Schlüssel fungiert als isoliertes Zugriffstoken: Er ermöglicht es der App lediglich, anonyme Textanfragen zu stellen. Ihre privaten Daten bleiben absolut sicher.

Pour des raisons de sécurité importantes, cette application de dictionnaire ne demande jamais d'adresses e-mail ou de mots de passe. Une clé API fonctionne comme un jeton d'accès isolé : elle permet uniquement à l'application d'effectuer des requêtes textuelles anonymes. Vos données privées restent absolument sécurisées.

OpenRouter (Kostenlose Modelle)

OpenRouter (Modèles gratuits)

OpenRouter bündelt Dutzende KIs an einem Ort. Es bietet Zugang zu komplett kostenlosen Modellen wie Mistral oder Llama 3 Instruct (Free) - perfekt, um das KI-Wörterbuch kostenlos zu nutzen.

OpenRouter regroupe des dizaines d'IA en un seul endroit. Il offre un accès à des modèles entièrement gratuits comme Mistral ou Llama 3 Instruct (Free) - parfait pour utiliser le dictionnaire IA gratuitement.

  1. Erstellen Sie ein kostenloses Konto auf OpenRouter.
  2. Navigieren Sie zum Bereich Keys (Schlüssel) in Ihrem Dashboard.
  3. Klicken Sie auf Create Key, geben Sie einen Namen ein und kopieren Sie den Schlüssel.
  1. Créez un compte gratuit sur OpenRouter.
  2. Accédez à la section Keys (Clés) dans votre tableau de bord.
  3. Cliquez sur Create Key, entrez un nom et copiez la clé.
